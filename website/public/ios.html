Zero-Click Campus Auto-Login for iOS

Apple strictly prohibits persistent background third-party daemons on iOS. However, Apple Shortcuts Personal Automation runs at the hardware Wi-Fi layer — logging your iPhone or iPad into the campus captive portal silently the exact moment you connect.

⚡

How It Works: Native Hardware-Level Automation

You don't need to keep any third-party apps open. Using the built-in Apple Shortcuts app on your iPhone:
  • Trigger: iOS detects connection to PESU-EC-Campus, PESU-RR-Campus, or AMAATRA-HOSTEL.
  • Execution: iOS silently dispatches the Sophos / Cyberoam authentication packet (mode=191) in <200ms.
  • Experience: Seamless, unbroken internet connectivity as soon as you walk into campus or hostel.
Step 1

Create the "PESU WiFi Login" Shortcut

Open the Shortcuts app on your iPhone or iPad, tap the + button in the top right corner to create a new shortcut, and name it PESU WiFi Login.

Add the following 3 native actions in order:

  1. Action 1 — Text: Add a Text block with your target gateway URL:
    http://192.168.254.1:8090/login.xml (PESU EC & RR Campus)
    Hostel residents: use http://172.16.1.1:8090/login.xml for Amaatra.
  2. Action 2 — Get Contents of URL:
    Tap Show More on the action and configure:
    • Method: POST
    • Headers: Add Header User-Agent = Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X)
    • Request Body: Set to Form
    • Add Key mode = 191
    • Add Key username = Your PESU SRN / Username
    • Add Key password = Your Wi-Fi Password
    • Add Key a = 1700000000000
    • Add Key producttype = 0
  3. Action 3 — Show Notification (Optional):
    Add Show Notification with text: "PESU WiFi: Connected as [Your Username]!"

🛡️

Using a VPN on iOS? (Tailscale, WireGuard, WARP, AdGuard)

If your iPhone has an active VPN when connecting to campus Wi-Fi, the portal request will fail because the VPN tries to route the local campus IP (192.168.254.1) through the encrypted tunnel. You can make it 100% automatic using either option:

  • Option A — Add Native "Set VPN" Actions to your Shortcut (Recommended):
    Add Set VPN → Disconnect as the very first action, and Set VPN → Connect at the end (after a 1-second Wait). This guarantees silent login on local Wi-Fi, then instantly re-secures your traffic with your VPN!
  • Option B — Enable "Allow Local Network Access" in your VPN app:
    In Tailscale, toggle on "Allow Local Network Access". In WireGuard or WARP, exclude local RFC-1918 subnets (192.168.0.0/16, 172.16.0.0/12) under Split Tunnel settings.

Step 2

Set Up "Run Immediately" Personal Automation

This step makes authentication 100% automatic without having to tap anything when you connect to Wi-Fi.

  • In the Shortcuts app, tap the Automation tab at the bottom.
  • Tap the + button (or "New Automation").
  • Scroll down and tap Wi-Fi.
  • Tap Choose Network and select your campus networks:
    PESU-EC-Campus, PESU-RR-Campus, and/or AMAATRA-HOSTEL.
  • Select "Run Immediately". (Crucial: this prevents iOS from asking for manual confirmation).
  • Toggle "Notify When Run" to OFF if you want completely silent background sign-in.
  • Tap Next, then choose the PESU WiFi Login shortcut you created in Step 1.
🎉 You're all set! Whenever your iPhone connects to campus Wi-Fi, it will execute the login instantly.
Step 3 (Optional)

Add 1-Tap Widget or Action Button

For manual control whenever you want to trigger re-authentication or disconnect:

  • Home Screen Widget: Long-press your home screen, tap +, search for Shortcuts, and add the 1-tap button.
  • Action Button (iPhone 15 Pro / 16): Go to Settings → Action Button → Shortcut, and select PESU WiFi Login.
  • Control Center (iOS 18): Add the Shortcut toggle directly inside Control Center.
Step 4 (Optional)

1-Tap Logout Shortcut

Campus firewalls enforce strict concurrent device limits. If you want to log out of your iPhone before using your laptop:

  • Create a second shortcut named PESU WiFi Logout.
  • Add Get Contents of URL with:
    URL: http://192.168.254.1:8090/logout.xml
    Method: POST
    Form Body: mode = 193, username = [Your SRN], producttype = 0.
  • Tap once to instantly liberate your session!
Pro Tips

iOS Wi-Fi Configuration Best Practices

  • Disable "Private Wi-Fi Address" on Campus:
    In iOS Settings → Wi-Fi → tap (i) next to PESU network, set Private Wi-Fi Address to Off. Random MAC rotation can cause the firewall to drop DHCP bindings.
  • Auto-Join:
    Ensure Auto-Join is enabled so your iPhone connects immediately when in range of campus APs.
  • Handling the Apple "Captive Portal Assistant" Popup:
    When first connecting, iOS may pop up a white login sheet. Tap Cancel in the top right, then tap "Use Without Internet". From then on, your Shortcut will authenticate silently without the popup interrupting you!
  • VPNs (Tailscale, WireGuard, WARP, AdGuard):
    Campus captive portals (192.168.254.1 or 172.16.1.1) exist exclusively on the local physical Wi-Fi network. To prevent VPN tunnels from dropping the connection:
    • Automated Pause in Shortcut: Add Apple Shortcuts' native "Set VPN → Disconnect" before the login action and "Set VPN → Connect" after.
    • Tailscale: Open iOS Settings → Tailscale → Toggle on "Allow Local Network Access".
    • Cloudflare WARP (1.1.1.1): Settings → Advanced → Connection options → Split Tunnels → Exclude 192.168.0.0/16 and 172.16.0.0/12.
    • WireGuard: In tunnel settings, ensure AllowedIPs excludes private RFC-1918 subnets or toggle "Exclude Private IPs".
